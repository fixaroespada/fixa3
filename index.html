THREAT KNOWLEDGE BASE

Attack types & field guide

Observed feed signals are separated from reference categories
LIVE FEED COVERAGE: Botnet C2 is currently classified by Feodo Tracker. Blocklist.de entries are generic hostile-IP reports unless the source supplies a more specific attack label. Other categories below are reference intelligence, not claims of current detections.
⌘OBSERVED · FEODO

Botnet Command & Control

IP infrastructure used by malware-infected devices to receive commands, coordinate activity or send stolen data.

Look for Repeated outbound connections to known C2 infrastructure.
Defend Block verified indicators, isolate affected hosts and investigate DNS / network logs.
◈GENERIC FEED

Hostile IP / Reputation

An address reported by a community blocklist. The report alone does not identify the exact technique or prove an active attack.

Look for The original report, timestamp, target service and repeated activity.
Defend Correlate with firewall and server logs before blocking or escalating.
⇄REFERENCE ONLY

SSH Brute Force

Repeated login attempts against SSH accounts, often testing common usernames or passwords.

Look for Failed SSH logins, repeated usernames and bursts from one or many IPs.
Defend Use SSH keys, disable password login where practical, enforce MFA and rate limits.
⌕REFERENCE ONLY

Web Exploit / SQL Injection

Requests crafted to exploit vulnerable web applications, including attempts to manipulate database queries.

Look for WAF alerts, unusual parameters, error spikes and suspicious request patterns.
Defend Patch frameworks, use parameterized queries and deploy a tuned WAF.
⌁REFERENCE ONLY

DDoS

Distributed traffic floods that aim to exhaust bandwidth, application capacity or network resources.

Look for Traffic / request surges, latency, packet rates and service availability changes.
Defend Use upstream DDoS protection, rate limiting, caching and an incident runbook.
◎REFERENCE ONLY

Port Scanning / Recon

Probing hosts and ports to discover exposed services before a possible intrusion attempt.

Look for Sequential port connections, many destination ports or broad host sweeps.
Defend Minimise exposed services, restrict management ports and monitor scan patterns.
✉REFERENCE ONLY

Phishing / Credential Theft

Deceptive messages or websites designed to steal passwords, session tokens or sensitive information.

Look for Lookalike domains, suspicious URLs, credential submissions and anomalous sign-ins.
Defend Enforce phishing-resistant MFA, email protections and user reporting workflows.
▣REFERENCE ONLY

Malware / Ransomware

Malicious software that can steal information, persist on a host, disrupt systems or encrypt files.

Look for Endpoint alerts, unusual process activity, persistence and unexpected file changes.
Defend Maintain offline backups, patch systems, use EDR and rehearse recovery.

REFERENCE GUIDE ONLY · Categories marked REFERENCE ONLY are not currently detected by the connected feeds. No attack type is inferred from a generic IP reputation entry.
